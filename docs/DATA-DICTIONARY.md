# 数据定义

区间首末号为闭区间，内部转为半开区间。序列号使用Python整数运算，对外按文本输出，大整数不经过浮点。事件时间必须带偏移且先转UTC；同刻按事件号排序。事件号冲突全部隔离，相同事件只采信一条。注销不可撤销，重复签发不能恢复证书。全局签发=各持有人可用+已注销；划拨只是持有人变化。

- 空串、`-`、`N/A`、`NULL`、`未知`是缺失哨兵，不作为零。
- 原始批号、事件号均为文本，保留前导零。
- CSV支持UTF-8 BOM和GB18030，必须有完整表头，支持列顺序调整。
- 文件最大2MB、10000条记录；读取时逐记录校验，计算阶段保留受此上限约束的数据。
- 空文件、全空行、仅表头分别标记EMPTY_FILE、BLANK_ONLY、HEADER_ONLY。
- 多余列隔离；非法引号导致整次请求失败，不保存半批。
- 幂等键=输入字节摘要+规则版本+参数；内容完全相同复用批次。
- 复核采用整数版本比较，旧版本返回409。

序列号最多40位，持仓和注销区间按签发宽度保留前导零。
