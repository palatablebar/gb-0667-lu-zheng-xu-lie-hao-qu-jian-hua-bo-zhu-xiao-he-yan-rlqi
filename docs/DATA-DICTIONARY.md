# 数据定义

区间首末号为闭区间，内部转为半开区间。序列号使用Python整数运算，对外按文本输出，大整数不经过浮点。事件时间必须带偏移且先转UTC；同刻按事件号排序。事件号冲突全部隔离，相同事件只采信一条。注销不可撤销，重复签发不能恢复证书。全局签发=各持有人可用+已注销；划拨只是持有人变化。

- 空串、`-`、`N/A`、`NULL`、`未知`是缺失哨兵，不作为零。
- 原始批号、事件号均为文本，保留前导零。
- CSV支持UTF-8 BOM和GB18030，必须有完整表头，支持列顺序调整。
- 文件最大2MB、10000条记录；读取时逐记录校验，计算阶段保留受此上限约束的数据。
- 空文件、全空行、仅表头分别标记EMPTY_FILE、BLANK_ONLY、HEADER_ONLY。
- 多余列隔离；非法引号导致整次请求失败，不保存半批。
- 幂等键=输入字节摘要+规则版本+参数；内容完全相同复用批次。
- 复核采用整数版本比较，旧版本返回409。

序列号最多40位，持仓和注销区间按签发宽度保留前导零。

## 月末关账差异账（M8）

- 来源三态：`internal`内部持仓、`exchange`交易所回执、`registry`注销登记；区间为闭区间，内部转半开，整数运算不走浮点。
- 区间结论互斥且唯一：`PENDING`待确认（无受理回执，禁止记已划出）、`RECEIPT_GAP`回执缺口、`INTERNAL_ONLY`内部独有、`REGISTER_ONLY`登记独有、`CONFLICT`三源冲突、`TRANSFERRED`已划出、`CANCELLED`已注销；后两者为终态。
- 状态迁移走白名单：待确认类可补凭据迁至已划出/已注销，终态不可回退；非法迁移返回`MUTEX_STATUS`。
- 凭据只追加不覆盖，旧凭据软保留；每次凭据修订递增台账版本，旧版本号提交返回409 `STALE_VERSION`。
- 差异账按期间单账管理，`(台账,批号,起,止)`为唯一区间键；重跑输入未变不新增记录、不升版；输入变化在单事务整体替换，旧条目置`superseded`软保留，失败回滚保留旧版并登记`last_error`。
- 关账要求待确认差异清零，否则返回`PENDING_OPEN`。
